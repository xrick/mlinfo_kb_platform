# 任務完成檢查清單

## 開發完成後必須執行
1. **功能測試**: 測試新功能是否正常運作
2. **健康檢查**: 確認 `/health` 端點正常回應
3. **系統狀態**: 確認 `/status` 端點顯示正確狀態
4. **日誌檢查**: 查看 `salesrag.log` 確認無錯誤
5. **資料庫連線**: 確認 Milvus、DuckDB、SQLite 連線正常

## 混合搜索系統特別檢查
1. **集合存在性**: 確認 Milvus 集合已建立
2. **索引狀態**: 確認向量索引已建立並載入
3. **搜索功能**: 測試查詢 "請介紹容易攜帶、輕便的筆電" 
4. **結果格式**: 確認回傳格式符合 MGFD 預期
5. **LLM 分析**: 確認 LLM 分析結果包含在回應中
